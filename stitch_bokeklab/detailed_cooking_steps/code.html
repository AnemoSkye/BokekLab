Spicy Chicken Rendang

Langkah Memasak

1

Panaskan minyak, tumis bumbu halus, serai, daun jeruk, dan asam kandis hingga harum.

skillet Wajan Besar
cooking Spatula Kayu
2

Masukkan potongan daging ayam segar, aduk rata dengan bumbu hingga ayam berubah warna dan permukaannya sedikit tertutup bumbu.

local_fire_department Api Sedang
3

Tuang santan perlahan. Masak dengan api kecil sambil terus diaduk perlahan dari dasar wajan agar santan tidak pecah. Lanjutkan memasak hingga bumbu meresap sempurna, ayam menjadi sangat empuk, dan kuah mengering mengeluarkan minyak.

timer 45-60 Menit
local_fire_department Api Kecil

Siap disajikan dengan nasi hangat dan taburan bawang goreng.
